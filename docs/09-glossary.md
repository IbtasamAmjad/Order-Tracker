# 09 - Glossary

The meeting transcript is machine-generated and mixes English with Urdu/Hindi, so many words are misspelled (for example "Cardigar", "Shivani", "Anguta chap"). Use this table to read it correctly.

| Term | Meaning |
|---|---|
| **Anas** | The business owner and the **Admin** of the app. |
| **Adnan, Muhammad** | The developers/advisers in the meeting. |
| **Karigar** (also "cardigar", "carikers", "carrier" in the transcript) | A craftsman or skilled worker (embroiderer, tailor, etc.). |
| **Master** | The head karigar or head-office person who manages a group of karigars and is the app's second user level. On Anas's payroll; his own workers are on his payroll. |
| **Sherwani** (also "Shivani", "Shervani") | A long formal coat worn by grooms. Anas's main product. |
| **Kurta** | A long shirt/tunic. |
| **Pants / Pajama / Shalwar** | Trousers worn with a kurta. |
| **Pagri** (also "Pagiri") | A turban, often worn with a Sherwani. |
| **Shawl** | A wrap worn over the outfit. |
| **Indo-western** | A hybrid style, mentioned as a future sub-category. |
| **Sharara, Gharara, Dupatta** | Ladies' traditional garments (the ladies' line run by Anas's wife). |
| **Bridal** | Ladies' wedding wear category. |
| **Cutting master** | The person who measures, cuts the fabric, and later stitches. |
| **Embroidery karigar** | The craftsman who does hand embroidery (about 5-15 days). |
| **Checker** | The person who checks measurements and finishing before packing. |
| **Accountant** | Creates the invoice/bill before shipping. |
| **Shipping company** | The courier that ships the packed garments abroad. |
| **Custom order** | A made-to-measure order for one customer. The app is for these only. |
| **Order number** | The number identifying an order. Primary identifier (customer names repeat). |
| **My due date** | Anas's real delivery date to the customer. **Admin-only.** |
| **Karigar due date** | The date the master/karigar must finish by (earlier than Anas's real date). Visible to the master. |
| **Priority / sequence** | The position of an order in the list. Moving an order up makes it urgent. Only Admin can change it. |
| **Photo gate** | A stage that locks until a photo is uploaded and approved. |
| **Template** | A pre-built form for a sub-category (fields + stages) so Anas doesn't re-enter the same fields for every order. |
| **Category / sub-category** | Two-level grouping, for example Men > Sherwani. |
| **Archive** | Where completed and cancelled orders go, out of the way. |
| **PIN** | A short personal code a master enters after opening their link. |
| **PWA** | Progressive Web App: a website that can be added to a phone's home screen like an app. |
| **Kanban** | A board of cards by status/priority. Anas uses it as the idea ("every order is a task"), but not as a literal off-the-shelf tool. |
| **Chalan / challan** | A delivery note or bill accompanying goods. |
| **Rupees (Rs)** | Local currency; printing costs about 10 Rs per page. |
